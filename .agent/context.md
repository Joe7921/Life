# 烦恼扫射 - 全局开发上下文

## 项目概览
"烦恼扫射"：寓意人生不同节点有不同烦恼，用户用武器逐一击破烦恼，通关人生。
单文件游戏：`index.html`（约 4100+ 行）

## 已完成阶段

### 阶段一：幼年（1-12岁）
- 10种烦恼怪物：独处、训斥、作业、考试、错题、偏科、霸凌、唠叨、补课、管束
- Boss：学业（定时召唤 作业/考试/错题/偏科）
- 击杀即获取经验，年龄增长，每升一岁抽卡

### 阶段二：青年（13-35岁）
- 16种烦恼怪物：霸凌、唠叨、补课、管束、失恋、社恐、考证、迷茫、挂科、论文、备考、绩点、异地、催婚、相亲、DDL
- 精英怪：焦虑、抑郁（低伤害+减速debuff）
- 双子星Boss：学业+事业（35岁触发，召唤精英怪）

### 阶段三：中年（36-55岁）
- 16种烦恼怪物：加班、压榨、甩锅、低薪、刁难、业绩、催婚、相亲、车贷、房贷、失业、应酬、养老、失眠、发胖、脱发
- Boss：重压（55岁触发）
  - 承压期→暴走期(HP<20%)→虚脱期(3倍伤害窗口)

### 阶段四：老年（56-70岁）
- 6种烦恼怪物：孤独、健忘、衰弱、失眠、耳聋、眼花
- Boss：病痛（70岁触发，紫色主题）
  - 每6秒召唤1-2只疾病精英怪（递增）
- 6种疾病精英怪（具有弹幕射击能力）：
  - 糖尿病(90帧射击间隔)、高血压(75帧)、关节炎(120帧)
  - 胆结石(100帧)、焦虑症(60帧最快)、癌症(50帧最快+高血量)
  - 弹幕伤害低(1点)，鼓励玩家优先处理精英怪再打Boss

## 核心机制
- **卡牌系统**：7种塔罗牌，白牌正面增益，黑牌强力增益+反噬
- **黑牌诅咒15秒限时**：反噬效果15秒后自动解除
- **9合1底牌**：保留1张正位白牌作为"底蕴牌"防裸奔
- **清屏无敌5秒**：合成底牌时清屏+清弹幕+5秒无敌
- **敌方弹幕系统**：enemyBulletsArray，疾病精英怪定时向玩家射击

## 难度曲线
- 阶段一7岁前：原曲线不动
- 阶段一7岁后：生怪减缓，速度封顶1.25x
- 阶段二/三/四：独立缩放系数

## 最近优化与修复
- **稳定性修复**：引入抽卡动画队列（`drawQueue`），解决由于快速连续升级导致的并发抽卡动画冲突和游戏死锁问题。
- **UI 纯净化**：
  - 移除了左下角冗余的“系统状态指数”面板。
  - 将卡牌的数值加成/反噬效果从发牌 UI 卡面上移除，统一整合到占卜师头顶的对话气泡中展示。
- **节奏拉升**：全局基础经验获取速度大幅提升 40%（结合此前第一阶段已有的 10% 经验提升，使整体成型更快）。
- **底层性能重构**：
  - 移除高频碰撞检测中的 `Math.hypot`（开平方运算），替换为平方距离比较，极大降低 CPU 计算开销。
  - 实现 `fastRemove` (Swap-and-Pop) 数组快速删除机制，将删除失效弹幕/怪物/特效的时间复杂度从 O(N) 降至 O(1)，告别后期卡顿。
